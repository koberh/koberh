## Current work

**MIRHIQL — MORE + Patient-Centered Opioid Tapering** (Garland Center / Cooperman Lab, Rutgers R01)  
Hybrid type 2 implementation-effectiveness RCT (N=300) testing Mindfulness-Oriented Recovery Enhancement (MORE) combined with patient-centered opioid tapering for chronic pain patients on long-term opioid therapy. Delivered as an insurance-reimbursable group medical visit across primary care clinics in Utah and New Jersey.

**Mindful Kidney** (Yale, PI: Garrett Ash PhD)  
6-week pilot RCT evaluating the Calm Health mindfulness app in adults with chronic kidney disease (n=26). I independently developed a 5-phase LSTM pipeline for within-person blood pressure trend estimation from wrist PPG (ActiGraph LEAP), built automated biometric report generation, and managed wearable data collection via the CentrePoint V3 REST API. Key finding: domain-matched retraining (ICU → ambulatory data) improved ambulatory SBP prediction from r=−0.10 to r=+0.48.
